&#x20;Анализ безопасности API Calculator



&#x20;1. Используемые инструменты



В CI/CD-пайплайн проекта добавлены два open-source инструмента анализа безопасности:



\- \*\*Semgrep\*\* — статический анализ исходного кода и конфигурационных файлов;

\- \*\*Trivy\*\* — анализ Docker-образа, системных пакетов и библиотек на известные уязвимости.



Проверки выполняются автоматически средствами GitHub Actions при каждом push в ветку `main`.



Помимо проверок безопасности в пайплайне сохранены этапы предыдущей версии проекта: установка зависимостей, проверка приложения, сборка Docker-образа, запуск контейнера и автоматическая проверка версии API.

&#x20;2.1 Результаты Semgrep



По результатам выполненного анализа Semgrep обнаружено 6 замечаний.



Параметры проверки:



\- проверено целей — 8;

\- выполнено правил — 329;

\- найдено замечаний — 6;

\- blocking findings — 6.



Из обнаруженных замечаний:



\- 5 связаны с использованием изменяемых тегов GitHub Actions, например `actions/checkout@v4`, `actions/setup-python@v5` и `aquasecurity/trivy-action@v0.36.0`;

\- 1 замечание связано с отсутствием директивы `USER` в Dockerfile, из-за чего приложение внутри контейнера по умолчанию запускается от пользователя root.



Для повышения безопасности рекомендуется закрепить используемые GitHub Actions на конкретные commit SHA и запускать приложение в Docker-контейнере от отдельного непривилегированного пользователя.

По результатам выполненного сканирования Docker-образа версии `1.0.6` обнаружено:

\\- уязвимости в Python-пакетах — 4;

\\- уровень HIGH — 4;

\\- уровень CRITICAL — 0.



Выявлены следующие уязвимые компоненты:

\\- `setuptools` версии 70.3.0 — CVE-2025-47273, уровень HIGH; исправленная версия 78.1.1;
