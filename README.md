\# API Calculator



API-калькулятор на Python с использованием FastAPI.



\## Операции

\- сложение

\- вычитание

\- умножение

\- деление

\- возведение в степень



\## Локальный запуск

py -3.13 -m uvicorn main:app --reload



Swagger:

http://127.0.0.1:8000/docs



\## Docker

Сборка:

docker build -t calculator-api .



Запуск:

docker run --name calculator-container -p 8000:8000 calculator-api



\## Дополнительные методы



\- `/mod` — остаток от деления

\- `/version` — текущая версия приложения



\## CI/CD



Для проекта настроен GitHub Actions.



При каждом push в ветку `main` автоматически выполняются:



\- получение исходного кода;

\- установка Python 3.13;

\- установка зависимостей;

\- проверка запуска приложения;

\- сборка Docker-образа;

\- запуск контейнера;

\- проверка версии API.



Версия Docker-образа и приложения формируется автоматически по номеру запуска GitHub Actions.



Пример версии:



1.0.3
